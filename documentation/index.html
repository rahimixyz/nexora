Nexora

Crypto & Web3 Dashboard React Template · Version 1.0.0

Thank you for using Nexora! Nexora is free and open source under the MIT License. It is a clean, responsive crypto dashboard template built with React 18, TypeScript, Tailwind CSS and Recharts. It ships with 10 ready-made pages, light and dark themes, 5 accent color presets and fully typed demo data that you can replace with your own API.

Nexora is a front-end template. It contains no backend, no smart contracts and no real trading logic. All prices, balances and transactions are demo data.

Requirements

  • Node.js 20.19 or newer (includes npm)
  • A code editor, for example VS Code
  • Basic knowledge of React and Tailwind CSS

Installation

Clone or download the repository, open a terminal in the project folder and run:

npm install
npm run dev

Open http://localhost:5173 in your browser. Changes you save are reloaded instantly.

CommandWhat it does
npm run devStarts the development server with hot reload
npm run buildType-checks and builds the production files into dist/
npm run build:demoBuilds into docs/ for GitHub Pages
npm run previewServes the production build locally for testing

Deployment

Run npm run build and upload everything inside the dist/ folder to your host. The template uses hash-based routing (/#/markets) and relative asset paths, so it works on any static host or in a sub-folder with no server configuration.

Prefer clean URLs (/markets)? Replace HashRouter with BrowserRouter in src/main.tsx and configure your host to send all routes to index.html.

Branding & logo

  • Logo and name: edit src/components/Logo.tsx. Replace the SVG with your own or use an <img>.
  • Favicon: replace public/favicon.svg.
  • Page title and description: edit index.html.
  • Fonts: Inter and Poppins are bundled locally through Fontsource (imported in src/main.tsx) and set in tailwind.config.js.

Colors & dark mode

The brand color is controlled by CSS variables, so users can switch it at runtime from Settings → Appearance. Presets live at the top of src/index.css:

[data-accent='red'] {
  --brand-50: 255 241 242;
  --brand-500: 244 63 94;
  --brand-600: 225 29 72;   /* main button color */
  --brand-700: 190 18 60;
}

To add your own preset, copy one block, change the RGB values and add it to the ACCENTS list in src/context/ThemeContext.tsx. To change the default theme or accent, edit the fallback values in the useState calls of ThemeProvider.

Dark mode uses Tailwind's class strategy. The user's choice is saved in the browser.

Connecting real data

All demo data is in src/data/mock.ts and is fully typed (Coin, Transaction). To use live data, fetch it from your API or a market-data provider and return objects of the same shape. A simple example:

// src/data/api.ts
export async function fetchCoins(): Promise<Coin[]> {
  const res = await fetch('https://your-api.example.com/coins')
  return res.json()
}

Then load it in a page with useEffect or a library such as TanStack Query. The swap page reads its platform fee from the FEE constant in src/pages/Swap.tsx.

Components

Reusable pieces in src/components/ui.tsx: CoinIcon, Change (up/down percentage), Sparkline, StatusBadge, PageHeader, Segmented and Toggle. Common styles such as .card, .btn-primary, .btn-ghost, .input and .label are defined in src/index.css.
